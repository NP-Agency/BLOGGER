# Changelog

All notable changes to the YourSacralGuide Blogger theme will be tracked here.

This project follows semantic versioning for theme releases:

- Patch: visual fixes, Blogger XML fixes, copy updates, small compatibility changes.
- Minor: new sections, new Blogger widget support, meaningful layout additions.
- Major: breaking template structure changes or migration-heavy redesigns.

## 1.0.0 - 2026-05-14

- Initial version-controlled Blogger theme baseline.
