# Pencil Design Files

Place one Pencil `.pen` file per component in this folder.

See `docs/PENCIL-COMPONENTS.MD` for the full component list and target code file for each design. Use `docs/PENCIL-SUMMARY.MD` for both directions:

- Design to code: create a `.pen` visual component, then ask Pencil AI to generate Hamlet + Tailwind.
- Code to design: paste an existing Hamlet + Tailwind partial into Pencil AI, then ask it to create an editable `.pen` visual component.

See `docs/PENCIL-COMPONENT-PROMPTS.MD` for per-component prompts. Each starter `.pen` file also contains:

- `pencil-visual-prompt`: prompt for generating/refining the visual component.
- `html-css-code-prompt`: prompt for generating the matching Hamlet/Tailwind partial.

Recommended starting files:

```text
01-announcement-bar.pen
02-header-navigation.pen
03-home-hero.pen
04-trust-strip.pen
05-blog-feed.pen
06-post-card.pen
07-post-page.pen
08-taxonomy-filters.pen
09-pagination.pen
10-sidebar.pen
11-newsletter-cta.pen
12-footer.pen
```
